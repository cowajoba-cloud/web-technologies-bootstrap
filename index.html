DESIGN DECISIONS

The Thinking Behind the Build

I have treated this as a small working product rather than a static mock-up. Bootstrap provides responsive layout components, while a separate stylesheet controls the project’s visual identity and an external JavaScript file manages interactions.

The breed explorer uses a user selection to make an API request. The contact form demonstrates browser-side validation; it does not claim to send or store submissions.
